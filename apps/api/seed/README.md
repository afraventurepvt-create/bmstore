# Seed data

- `demo-products.csv`: 25 products across 4 categories for the demo store (`npm run seed:demo`). Placeholder images
  are generated by the seed and pushed through the real media pipeline, so `image_filename` resolves.
- `test-500-products.csv`: 500 products across 20 categories, no images. Used by `test/seed.spec.ts` to prove a
  500-row import succeeds; handy for load-testing the import screen.
